# keylogger-and-keylogger-detector

A cybersecurity project demonstrating how keystroke logging works and how suspicious keylogger activity can be detected and monitored.

## 🔐 Project Overview

This project contains two components:

* **Keylogger** — Demonstrates keystroke logging for educational and authorized security-testing purposes.
* **Keylogger Detector** — Identifies suspicious keylogging activity and helps detect potentially malicious processes.

The project was developed to understand endpoint security, process monitoring, threat detection, and basic malware-analysis concepts.

## 🛠️ Technologies Used

* Python
* Process Monitoring
* File & System Monitoring
* Windows/Linux Security Concepts
* Cybersecurity & Threat Detection
